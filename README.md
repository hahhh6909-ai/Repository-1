# NeonGuard Toolkit

Node.js security and communication toolkit for Termux.

## Features

- Local OTP generation and verification
- SMS integration through Twilio
- WhatsApp messaging through Twilio
- Authorized voice notifications
- HTTPS link dispatcher
- Recipient allowlist and rate limits

## Requirements

- Node.js 20+
- Twilio account for external messaging
- Authorized recipients who have opted in

## Installation

```bash
npm install
cp .env.example .env
nano .env
npm start# NeonGuard Toolkit
